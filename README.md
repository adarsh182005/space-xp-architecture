# SPACE XP. React Website

## Stack
- React 18
- Vite
- Lucide React
- Plain CSS

## Start
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Main source
- `src/main.jsx` — React components and project data
- `src/styles.css` — complete visual system and responsive layout

Replace the Unsplash URLs in `src/main.jsx` with final SPACE XP. project photography.

The current implementation uses a typographic SPACE XP. placeholder because the actual logo image asset was not included with the supplied text brief.
